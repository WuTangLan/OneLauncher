# One Launcher — handoff notes for Claude Code

Custom home-screen launcher for a **Philips 55PUS8558 "The One"** TV (Google TV, Android 12+,
1080p → 960 × 540 dp, controlled only by a D-pad remote). Owner: Marcus. The user-facing guide
is `README.md`; this file is for whoever continues development.

## Status at handoff (2026-10-25)

Built in a cloud session that could **not** run Gradle/AGP or a device. What has been verified:

| Verified | How |
|---|---|
| All Kotlin + Java compiles | `kotlinc` 2.0.21 against `android-35` `android.jar` with a stub `R` class |
| Every `@drawable/@layout/@style/@id` reference in XML exists, all XML well-formed | script |
| `FtpServer.java` works | real FTP client: login, LIST, RETR, STOR 5 MB round-trip, REST resume, rename, mkdir/rmdir, path-escape blocked, UTF-8 names |
| Layout fits one screen | HTML mockup at identical dp sizes (`design/mockup.html`) |

**Never done yet:** a real `./gradlew assembleDebug`, aapt2 resource linking, or running on the
TV. Your **first job** is to build, fix whatever the real toolchain reports, then smoke-test on
the device (checklist below).

## Build & run

```bash
./gradlew assembleDebug          # → app/build/outputs/apk/debug/app-debug.apk
adb connect <TV-IP>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.marcus.onelauncher/.MainActivity
adb logcat -s AndroidRuntime:E    # crashes
```

**JDK:** Gradle 8.10.2 runs on Java 17–23 only. On the user's PC Android Studio's bundled
`jbr` is **Java 25** and fails (the whole error is just "25.0.3"). Use the JBR 21 that Studio
downloaded instead: `JAVA_HOME=~/.jdks/jbr-21.0.11` (Windows: `C:\Users\arcus\.jdks\jbr-21.0.11`).
`adb` is in `platform-tools/` at the repo root; the TV is usually `192.168.100.86:5555`.
The debug build was first built and installed on the TV on 2026-10-25 and runs.

Optional upgrade (do it only after the current setup builds): AGP 9.x + Gradle ≥ 9.1 runs on
Java 25. AGP 9 has built-in Kotlin support, so remove the `org.jetbrains.kotlin.android` plugin
(or set `android.builtInKotlin=false`) and re-check the `kotlinOptions` block.

CI: `.github/workflows/build.yml` builds a release APK (signed with the debug key) on push.

## Rules for this codebase

- **No third-party libraries, no AndroidX, no Compose.** Plain framework `Activity` + Views +
  `org.json` + `HttpURLConnection`. Keep the APK tiny and fast on a low-RAM TV.
- **Remote-first:** every action must be reachable with D-pad + OK + hold-OK + Back. Every
  interactive view is `focusable`; check focus order whenever layout changes.
- **One screen:** header + Favourites + Inputs + All Apps must fit in 960 × 540 dp without
  vertical scrolling. Update `design/mockup.html` when sizes change and screenshot it.
- Background work: `kotlin.concurrent.thread {}` + post to the main `Handler`. Never block the UI.
- User-visible text is plain English, short, sentence case ("Select to clean").
- `minSdk 28`, `targetSdk`/`compileSdk 35`, Java 17 bytecode.

## Design system (Apple TV–inspired, original — no Apple assets)

- Background near-black with soft radial colour glows (`wallpaper.xml`, `wp_*.xml`).
- Glass cards: `#1FFFFFFF` fill, 1 dp `#1FFFFFFF` stroke, 18 dp radius; **focused = white
  platter** `#F2FFFFFF` with dark text `#1C1C1E` / secondary `#636366`, scale 1.05
  (`card_bg.xml`, `applyPlatterColors()` in `MainActivity`).
- Tiles: 140 × 84 dp, 14 dp radius, focus = scale 1.12 + elevation + top sheen (`tile_fg.xml`);
  app name appears under banner tiles only while focused.
- Accents: blue `#0A84FF`, green `#30D158`, orange `#FF9F0A`, secondary text `#8CEBEBF5`.
- Section titles 13 sp medium, sentence case. Clock/temperature 34 sp regular.
- Icons are vector drawables. Weather (`wx_*`) and input (`ic_gamepad/pc/settopbox`) icons are
  generated by `tools/icons.py` / `tools/input_icons.py`, which also write an HTML sheet so you
  can eyeball them: `python3 tools/icons.py /tmp/sheet.html`.

## Device smoke-test checklist (do these on the real TV)

1. App launches from the app list; no crash in logcat.
2. **Inputs row** lists the HDMI ports. Philips firmware may hide inputs from third-party apps
   or reject `TvContract.buildChannelUriForPassthroughInput` intents. If so, investigate a
   Philips-specific fallback (e.g. the TV's own source/input-picker activity via
   `adb shell dumpsys package` / `cmd package query-activities`).
3. Hold OK on an input → rename → name + icon update and survive a reboot.
4. Hold OK on apps → add/move/remove favourites; Launcher options → Edit favourites.
5. Memory card cleans and the number changes.
6. File Transfer: on → FileZilla connects (passive) → upload an APK (install prompt) and a
   photo into `/Wallpapers` ("use as wallpaper" prompt). Foreground service type `specialUse`
   must not crash on the TV's Android version.
7. Wallpaper picker: live preview while moving, Back reverts, OK keeps; rotation setting works.
8. Weather appears within a few seconds online; city search works with the on-screen keyboard.
9. Home key returns to the launcher once the stock launcher is disabled (README §3).

## Google Home (verified on the TV, 2026-10-25)

The TV has **no AppWidget providers** and `SmartHomeStateContentProvider` isn't readable, so a
live device widget isn't possible. The Home panel is
`com.google.android.apps.tv.dreamx/…smarthome.core.SmartHomeMainActivity`, exported with no
permission, opened by action `com.google.android.libraries.tv.smarthome.intent.action.OPEN_SMART_HOME`
(`AppRepository.googleHomeIntent()`). It's in `dreamx`, not `launcherx`, so it survives disabling
the stock launcher. It's the round `home_button` (`round_bg.xml`) left of the clock card,
shown only if the intent resolves and `show_google_home` is on.

## Layout notes

- Rows: the zoom room (top/start padding) is on the `Row` style with `clipToPadding=false`,
  **not** on the `HorizontalScrollView`. A parent with `clipChildren=true` clips each child to the
  child's own bounds, so padding on the scroll view cut the top off zoomed tiles. Same in
  `wallpaper_picker.xml`.
- Now playing: `np_card` (weight 1) appears only while a session plays/pauses; `setCompact()`
  shrinks File Transfer to 150 dp and Memory to 128 dp with short texts, hides `header_space`,
  and narrows the weather line. Needs notification-listener access (README).
- `rows_space_top/bottom` get weight 1 only while All Apps is hidden, centring the two rows.
- `root_scroll` is made non-focusable in code (ScrollView forces focusable in its constructor),
  and the first `loadRows()` always focuses the first favourite.
